# Cangre Burger's - Menú Digital 🍔

Menú digital interactivo desarrollado para un restaurante local. 

## Características:
- Catálogo de productos con fotos.
- Carrito de compras dinámico (suma y resta cantidades).
- Integración directa con la API de WhatsApp para envío de pedidos.
- Diseño responsive (adaptado a teléfonos móviles).
- Precios diferenciados (Online y Local) con lógica de descuentos.

## Tecnologías usadas:
- HTML5
- CSS3 (Variables, Flexbox, diseño oscuro)
- JavaScript (Vanilla)
